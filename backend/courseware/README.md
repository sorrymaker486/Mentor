# Mentor 课程知识库

本目录会被 Docker 复制到生产镜像中，是 AI 带学、资源生成、知识导图的课程依据。

## 命名规范

- 每门课程至少提供一份 `backend/courseware/<course_id>/index.md`。
- 如需更精细控制，可继续添加 `backend/courseware/<course_id>/<section_id>.md`。
- `section_id.md` 优先级最高；没有独立小节文件时，系统会从 `index.md` 中按章节或小节标题提取内容。

## 写作要求

- 只写课程内稳定、可核验的基础知识，不写未经验证的“速成口诀”。
- 每个知识点应包含：定义边界、使用条件、常见误区、练习方向。
- 不用夸张承诺，不把后续章节结论提前当作当前小节的主要依据。
- 所有文件使用 UTF-8 编码。
